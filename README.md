# 메이플 사냥 멈춤 알리미

바로 쓰기: https://lee5j.github.io/maple-noti/

설치 없이 브라우저만으로 메이플스토리 화면을 보고, 사냥이 멈추면 소리로 알려 주는 페이지입니다.

> 속사기 직업만 지원합니다. 사냥 중에 MP가 계속 변하는지로 사냥이 멈췄는지를 판단합니다.

## 사용법

1. PC의 Chrome 또는 Edge로 위 주소에 접속합니다.
2. [화면 공유]를 누르고 메이플스토리 창을 고릅니다.
3. [감시 시작]을 누릅니다.

## 알려 주는 것

| 항목 | 알림 |
|---|---|
| 사냥 | MP가 5초 동안 변하지 않을 때 |
| 룬 | 미니맵에 룬이 나타났을 때 (미니맵을 펼쳐 두세요) |
| 경쿠 | 경험치 쿠폰 효과가 끝났을 때 |
| 부스터 | 화면 위 '남은시간' 부스터가 끝났을 때 |

필요 없는 항목은 체크를 끄면 됩니다.

## PIP (작은 창)

[PIP]를 누르면 게임 위에 항상 떠 있는 작은 창이 열립니다.

- 감시 시작·중지 버튼과 사냥·룬·경쿠·부스터 칸이 있습니다. 칸을 누르면 그 감시를 켜고 끕니다.
- 알림이 울리면 해당 칸이 깜빡이고, 도우미 캐릭터가 말풍선으로 알려 줍니다. 말풍선은 누르면 닫힙니다.
- PIP를 쓰는 동안은 본 화면의 미리보기를 멈춰 CPU를 아낍니다.

## 게임 화면을 바꿨을 때

게임 창 크기나 UI 배치를 바꾸면 MP 바와 미니맵 위치를 다시 인식해야 합니다.

- MP 바: 위치를 못 읽게 되면 10초 안에 자동으로 다시 찾습니다.
- 미니맵: 자동으로 다시 찾지 않습니다. 미니맵 위치나 크기가 바뀌었다면 [공유 중지]를 누르고 [화면 공유]로 다시 공유하거나, 페이지를 새로고침한 뒤 다시 공유하세요.

## 참고

- 설정은 주소(URL)에 저장됩니다. 설정한 주소를 즐겨찾기해 두면 그대로 다시 쓸 수 있습니다.
- 지난 버전은 페이지 오른쪽 위 버전 목록에서 고를 수 있습니다.
- 도우미 캐릭터(재롱이·돌고래)는 Microsoft Office 도우미이며, 그림의 저작권은 Microsoft에 있습니다.
